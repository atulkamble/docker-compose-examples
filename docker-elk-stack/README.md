# Docker ELK Stack - Elasticsearch + Kibana

A complete logging and search solution with Elasticsearch and Kibana.

## 🚀 Features

- Elasticsearch 8.14 for search and analytics
- Kibana 8.14 for data visualization
- Single-node setup for development
- Production-scalable architecture

## 🛠️ Quick Start

```bash
git clone https://github.com/atulkamble/docker-elk-stack.git
cd docker-elk-stack
docker compose up -d

# Access services
open http://localhost:9200  # Elasticsearch
open http://localhost:5601  # Kibana
```
