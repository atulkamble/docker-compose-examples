# Docker Prometheus + Grafana - Monitoring Stack

A complete monitoring solution with Prometheus metrics collection and Grafana dashboards.

## 🚀 Features

- Prometheus 2.55 for metrics collection
- Grafana 11.1 for visualization
- Pre-configured data sources
- Production-ready monitoring

## 🛠️ Quick Start

```bash
git clone https://github.com/atulkamble/docker-prometheus-grafana.git
cd docker-prometheus-grafana
docker compose up -d

# Access services
open http://localhost:9090  # Prometheus
open http://localhost:3001  # Grafana (admin/admin)
```
